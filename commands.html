CLI REFERENCE

Blender Box
command reference.

Look up the commands for Windows setup, test execution, results, and recovery.

The usage below names the built executable blender-box. From a development checkout, replace it with go run ./cmd/blender-box. Use --json for structured output. The first-test guide walks through the required files and a complete cube test.

SHELLUsage · optional flags in brackets
blender-box plan --target PATH --payload PATH [--json]
blender-box doctor --target PATH --payload PATH [--timeout 2m] [--json]
blender-box windows check --target PATH [--json]
blender-box windows setup --target PATH --host-binary PATH [--apply] [--json]
blender-box run --target PATH --payload PATH [--evidence-dir PATH] [--timeout 15m] [--json]
blender-box status --target PATH --run RUN_ID [--timeout 2m] [--json]
blender-box stop --target PATH --run RUN_ID [--timeout 2m] [--json]

Available commands

windows setup
Preview installation. With --apply, install the runner and register its Windows Scheduled Task.
windows check
Check the Windows installation without changing it or starting Blender.
plan
Validate the connection settings and file list locally.
doctor
Check the Windows installation and support for your requested screenshots.
run
Run your script in Blender and collect the result and requested screenshots.
status
Read the saved state of a run, including after a lost connection.
stop
Stop the Blender session created for the specified Run ID.
RUN SAFETY

plan and setup preview run locally. windows check and doctor inspect the host. windows setup --apply writes to Windows, run starts Blender, and stop stops the run's owned session.

Replace PATH with the appropriate local file path and RUN_ID with the ID printed when the run starts. Square brackets mark optional flags. The cube tutorial uses a 20-minute timeout; the default run timeout is 15 minutes.
